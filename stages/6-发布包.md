# 阶段 6：发布包（停，等作者看成片）

```bash
T final                      # 合成：人声处理 + 配乐自动让位 + 音效，两遍响度归一到 -16 LUFS → out/final.mp4
T check                      # 体检 → out/check_report.json、out/check_sheet.jpg（每 15 秒一格）
T package <编号_片名>         # → <项目根>/发布包/<编号_片名>/
```

## 体检要过的

- 1920×1080、时长和时间线一致、-16 LUFS 上下 1 以内、真峰值低于 -1 dB。（限幅之后编码成 AAC，真峰值会再冒上去一点，`T final` 会自己把限幅线往下压到合格为止。）
- 成片的声音转写回来，和口播稿对得上（0.9 以上）；低了就去听是念错了还是被音乐盖住了。
- 禁用字在口播稿、字幕、发布文案、画面源码里都搜不到。
- **自己打开 `out/check_sheet.jpg` 逐格看**：字幕错位、遮挡、空画面、某一格和上一格一模一样（说明这 15 秒没换画面）。

## 打包之前要准备好的

1. **`发布文案.md`**（放在这一集的目录里）：
   - 三个备选标题（B 站 80 字以内，把结果或者数字放前面）
   - 简介（讲的 skill、原作者、原始链接、许可证；章节时间点，从 `timeline.json` 的 `chapters` 取）
   - 标签 8 到 10 个
   - 置顶评论（领取方式、口令原话、原始链接）和 3 条常见问题的回复
   - 抖音、视频号、小红书各一句更软的引导说法；提醒勾选"内容由 AI 生成"
   - 需要作者戴耳机听的位置清单
2. **`gift/`**：要送给观众的东西。
   - 别人的 skill：原文件原样放进去，加 `LICENSE` 原文、`来源.md`（原作者、原始链接、版本或提交号、下载日期）、`中文使用说明.md`。许可证不允许转发的，只放 `来源.md` 和安装命令。
   - 作者自己的 skill：用 `T export <目录>` 导出的干净版，不是直接拷贝本机目录。
3. `Cover.tsx` 三张封面都看过。

## 交给作者的时候说什么

- 发布包的路径，先看 `手机预览_720p.mp4`。
- 体检结果原样贴出来，包括没过的项。
- 需要戴耳机听的位置（来自体检报告的 `needs_ears` 加上阶段 4 记下的句子）。
- `运行记录.md` 里的卡点和人工介入，如实说。
- 哪些东西没做、没验证。

然后停下。作者看完说行：`T gate 成片 "作者说了什么"`。作者提了意见：改对应的阶段（改稿 → 重配那几句 → `T timeline` → `T mix` → 重渲受影响的部分 → `T final` → `T check` → `T package`），并且把这条意见写回 skill 的阶段文件。

**上传、发布、推送都由作者自己来。** 不替作者点发布。
