# 阶段 4：声音（自动；先给 2 句试听）

顺序：配音 → 时间线 → 配乐 → 音效和拼接。都是耗时的活，放后台跑，同时可以开始阶段 5（先 `T timeline --draft` 按字数估时间，把画面搭起来）。

## 配音

```bash
T tts a01 a02        # 先做头两句，把 vo/me/a01.wav、a02.wav 的路径给作者试听（不等回复）
T tts                # 全量。只做文本有改动的句子；写了键就强制重做那几句
```

- 每句最多念 4 遍，Whisper 听写打分，取最准、语速最接近 `voice_rate` 的一遍，再把句内超过 0.4 秒的停顿压到 0.28 秒。
- 跑完看最后一行：听写准确率低于 0.9 的句子列在那儿。先看听写出来的字是同音字误报（"他/它"）还是真念错了；真念错的改写那一句（换词、拆句、英文换个写法）再重配。
- 多音字单独记下来请作者听。听写把"量（liáng）完改了一版"写成了"亮完"，说明声调可能念错了，但同音不同字的误报也很多（陆游 / 路由），机器分不出来。
- **不要拉伸成品。** 想快：用加快过的参考音（`voice_speed`），或者压停顿。
- 累计念了多少遍会写进 `运行记录.md`，视频里常用这个数字。

## 时间线

```bash
T timeline           # → app/src/timeline.json、out/vo.wav
```

每句的起止、每个分句的起止、字幕分页（一页最多 20 字）、章节起点都在里面。之后任何一句重配，都要重跑它，再重跑 `T mix`。

## 配乐和音效：改 cues.json

- `beds`：三到四段不同情绪的纯音乐，每段写速度、调、时长和一段英文描述（乐器、律动、情绪，结尾写 no vocals）。**每期重写，不沿用上一期的描述。** `T music` 生成，每段几分钟。
- `plan`：哪段时间放哪段音乐。按章节情绪切换，交界处自动交叉淡化。两段之间留一个空档就是"停乐"，放在全片最该让人停一下的那句话上，一集最多一次。
- `sfx`：哪个词上放什么声音。`hit` 砸字、`sw` 甩动、`sub` 低频、`glitch` 故障、`sparkle` 亮晶晶、`rev` 反向吸入（它会提前 1.6 秒起，正好收在这个词上）。写 `hit` / `sw` 会在同类里轮着用。每句开头的甩动声和每章开头的低频是自动加的（`auto`）。
- 音效卡的词应该和画面里"砸进来"的东西是同一个词，所以等分镜表定了再补全 `sfx`。一分钟 6 到 10 个 `hit` 是热闹的口播节奏；讲解段落少放。
- `levels`：人声目标音量、配乐相对音量、侧链压缩比。作者说"音乐太小"就把 `bed_db` 从 -7 往 -5 调。

```bash
T music              # 生成 cues.json 里还没有的配乐段
T mix                # → out/bed.wav、out/sfx.wav
```

## 这一步机器查不了的

配音的语气、有没有电音、音乐的情绪对不对、音效合不合拍。把要听的位置（哪几句、第几秒）列给作者。
